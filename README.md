A 20-second vertical clip cut from the "GTA 6 - Funny Moments" livestream
compilation (143s–163s): IShowSpeed pushes an elderly woman off her red
mobility scooter and rides it while she crawls on the asphalt, with police
arriving at the end. Cropped to 720x1280, with Speed's facecam overlaid at
the top left. The hook text "HE STOLE HER MOBILITY SCOOTER" is on screen for
the first 11 seconds. From 12 seconds the pitch is on screen, readable for
eight seconds: "Make clips like this with AI and earn money on make.fun" plus
make.fun/bounty/gta6-clipper-01. The clip is silent: the source download was
video-only and its audio could not be fetched.

The clip is published public on YouTube as a Short. Its description carries
the bounty's line and the entrant's play code. This repository only hands in
the video's address: `VIDEO.json` names it, and `main.ts` copies that file to
`/output`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/VIDEO.json` is then byte for byte this directory's `VIDEO.json`.
